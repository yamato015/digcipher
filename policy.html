02 / CORRECTIONS

訂正依頼

DIGCIPHER は、出典付きの事実（FACT）と、編集上の読み解き（INTERPRETATION）を分けて掲載しています。出典の誤りや古くなった情報の報告を受け付ける方針です。

報告の際は、次の内容をお伝えください。

  • 対象ページの URL
  • 該当箇所
  • 根拠となる出典

04 / PRIVACY

プライバシー

このサイトの HTML・CSS・JavaScript を確認した時点（下記の最終更新日）の内容です。

  • Cookie は使用していません。
  • localStorage / sessionStorage などのブラウザ保存領域は使用していません。
  • アクセス解析・計測ツールは使用していません。
  • 外部スクリプトは読み込んでいません。外部フォントも使用していません。
  • フォームの送信機能はありません。サイト内の検索欄に入力した語は、閲覧しているブラウザ内のデータだけで照合され、外部へ送信していません。
  • 外部サーバーへの通信（fetch / XHR など）は行っていません。

このサイトは GitHub Pages で配信しており、ホスティング事業者がアクセスログ（IP アドレス等）を取得する場合があります。詳しくは GitHub のプライバシーステートメント ↗ をご覧ください。

出典などの外部リンクを開くと、遷移先サイトの方針が適用されます。

今後アクセス計測などを導入する場合は、このページを更新します。
